## 3. 真实的能力边界

### 3.1 产品现在能做什么

- **三栏首页**：56px 图标栏 + 索引栏 + 主区；灵感、项目、需求、插件四个入口。
- **搜索**：标题子串匹配，出联想，回车进结果页，结果带命中片段。
- **捕捉**：文字（一行输入）、录音（波形、暂停、按住空格对讲、录了即存）、录像（HTTP 媒体通道）。
- **组织**：置顶、归档、详情页；索引栏全量列表。
- **持久化**：SQLite + 媒体文件，都在 `.omora/`。
- **跨语言**：Python 产局部树 → TS 链接 → 渲染；事件带 handler id 回传。

### 3.2 产品现在不能做什么

- 不能新建项目 / 需求；两个页面是空页（各 14 行占位、零测试）。
- 不能让灵感、项目、需求互相关联——tagline 的核心承诺目前是 0 行代码。
- 不能跨域检索；搜索只搜 `ideas.title`。
- 不能转写、不能 AI、不能深色、不能窄屏、不能多端。
- 不能部署成网页：没有 server 入口，只有 `omora dev`。
- 没有发布物：无 tag、无安装包、无 release notes。

### 3.3 引擎现在能做什么

- **Slot 文档运行时**：链接期组合、三张索引、全量 / 纯数据 / 局部树三种更新、集合模板、权限薄层、审计、38 个 kind。
- **主会话**：默认入口走 Slot（Python 局部树 → TS 链接 → EngineRuntime/DocumentView）；启动首帧由 Vite 构建期编译。
- **V1 树**：节点契约与跨语言校验、构建期 compose、runtime mount、Page / State / When / Bind、Node scope——结构层已成立，更新层与协议层未接。
- **运行后来源**：自动发现 + 热更新，示例 `clock`。
- **桌面壳**：Electron 主进程在 `app/ui-engine/shell/`。

### 3.4 引擎没做完

- **每事件全树重建**：主会话仍交整份 view，TS 全树链接、全树替换。
- **最小节点更新未落**：V1 runtime 的 `replace` 是整份文档，没有 applyOps。
- **ops 协议未落**：协议仍是整份 view；Slot 侧有 ops 机器，但没接主路径。
- **真实页面不能构建期 compose**：`static_ui.py` 只编空态骨架。
- `reactions` 只解析、不执行；schema 不是单一来源。
- 运行后来源只接了本地示例；网络帧、订阅、媒体登记、来源账本未接。

## 4. 沉疴旧弊

### 4.1 旧弊：每事件 O(N) 全树重建

一次 UI 变更的链路：**事件 → 整份 view 序列化 → 整帧传输 → 全树链接 → 全树替换 → 按 id diff → 落 DOM**。每一层都是 O(N)。

项目自己的文档写过：`docs/design/packages.md` §7.3——“当前主会话每个事件交整份 view（重链 + 全量替换），渲染层按 id 复用 DOM”。DOM 复用省的是创建，不是遍历。

这不是“要不要优化”，是构造决定的：树小看不出来，树大必然出现。测试只能测拐点，不能测有没有拐点。

### 4.2 旧弊：运行时组织树

旧结构不是一棵树，而是多个局部树 + 集合模板，在运行时由 TS 链接成权威根树。启动与切页都要整棵链接；静态构建只覆盖空态骨架（`scripts/static_ui.py`），真实页面（带数据、多模式）仍由运行时组织。和 4.1 同源：**结构在运行时才成立**。

### 4.3 新弊：决策债

- 此前的 roadmap 把 V1 写成“接管主会话 → 退役 Slot”，但 V1 零接线。
- 发现矛盾后，又把它写成“扫雷、到期归档”，把架构修正降级成临时实验。
- 同一天三种定位，没有任何一份 ADR 记录“为什么”。

修法：[决策机制](decision-process.md) + [ADR-0004](../engine/decisions/0004-static-tree-minimal-updates.md)。V1 的定位以 ADR-0004 为准：目标架构，分阶段接管。

### 4.4 新弊：产品闭环缺失

- Idea 闭环：有捕获、搜索、置顶、归档；缺标签、关联、转写、回顾。
- Project 闭环：没有——项目页是空页。
- 需求（requirements）：占位，后置。

这是长期目标，不是当前主线；写在这里是为了不让它被“引擎优先”遮掉。

### 4.5 协议仍是全量帧

主会话的 `ui.render` / `ui.event` 都返回整份 view；`ui.snapshot` 也推整份。Slot 侧虽有 ops / data 的机器（`sdk/update.py`、`engine/document/ops.ts`），但没有接主路径，也不是 V1 树的形状。
