# ADR-0001：引擎命名为 Dendrolink

- **状态**：已接受（2026-11-13）
- **决策者**：项目作者 + Lead
- **相关**：[README](../README.md)、schema 与 kind 命名空间、论文标题

## 背景

这个 UI 运行时需要一个能独立发布的名字。它此前一直叫 “ui-engine”，但这个称呼只说明它跑在哪，没说明它是什么。

设计收敛后，它的本质不是“插件系统”：插件只是局部树的一种来源。真正的对象是**局部树**、**权威根树**，以及把前者链接成后者的**链接期引擎**。名字要贴着这个本质，而不是贴着承载方式。

## 候选

| 名字                  | 构成                   | 结论                     |
| --------------------- | ---------------------- | ------------------------ |
| Tessera / Tessellatum | 镶嵌画的一块砖         | 隐喻好，但有同名 UI 项目 |
| SlotLink              | Slot + Link            | 直白，偏工具名           |
| Composita             | 拉丁语“被拼合的东西”   | 学术、干净，但不体现“树” |
| Arborlink             | arbor（树）+ link      | 可以，但偏泛             |
| Linkroot              | link + root            | 撞同名公司               |
| Graft                 | 嫁接（局部树接到根树） | 撞同类运行时             |
| **Dendrolink**        | **dendro（树）+ link** | **采用**                 |

## 决定

正式名 **Dendrolink**，缩写 **Dendro**，中文口头叫**树链引擎**。

- 英文论文标题：_Dendrolink: A Link-Time Engine for Composing Local Trees into an Authoritative Root Tree_
- 中文标题：《Dendrolink：把局部树链接成权威根树的链接期引擎》
- 一句话：把局部树链接成权威根树的链接期引擎。

## 理由

1. **字面就对上本质**：dendro = 树，link = 链接；不靠隐喻也能读懂。
2. **标题自然**：名字、局部树、权威根树、链接期引擎能放进同一个标题。
3. **占用相对干净**：检索只撞到一个绘图库里的同名词条，没有同类系统。
4. **可缩写**：Dendro 短，适合做命名空间前缀。
5. **和承载方式解耦**：名字里没有 “plugin”，插件、worker、远程来源都成立。

## 影响

| 位置          | 取值                                                             |
| ------------- | ---------------------------------------------------------------- |
| schema        | `dendro.ui/1`                                                    |
| 引擎内置 kind | `dendro:slot` / `dendro:page` / `dendro:layer` / `dendro:window` |
| 宿主导入 kind | 保持 `ideas:card` 这种                                           |
| id 前缀       | `dendro.window` / `dendro.window.page`                           |
| CSS 前缀      | `dendro-`                                                        |
| 包名          | `@dendro/runtime`（或 `dendro-runtime`）                         |
| 文档目录      | `docs/engine/`                                                   |

旧命名空间 `omora.ui/2`、`omora:*`、`om.*` 在实现迁移时一起换掉；迁移前只存在于旧代码与旧草案中。

## 备注

这次命名不追求商标级的唯一性；如果将来独立发布/商业化，再做一次正式的商标与检索。当前只要满足“能读、能写进论文、搜索不撞同类系统”。
