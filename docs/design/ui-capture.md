# 捕捉工作区（就地展开 + 录了即存）

这份文档固定「首页三个大按钮点下去之后发生什么」。上一版把捕捉做成整页模式
（`capture_text` / `capture_audio` / `capture_video`），主区整页替换 —— 它有两个问题：

1. 捕捉页没有自己的版式：一个捕捉条贴在左上角，下面全是空的，三种媒体各长各的样。
2. 录完 / 写完立刻落库，用户没有一次「听一下 / 看一眼」的机会。

这一版改两件事：**就地展开**，和**录了即存**。

## 1. 决定

- **入口就地。** 点 `Tile` 不换页，把捕捉区那一块换成工作区。索引栏与列表面板不动。
  换页要多一次返回，而且屏幕会闪一下；就地换掉那一块更紧凑，也不打断「我正在首页」这件事。
- **录了即存。** 停止录制就是落库：没有「保存」按钮，也没有「要保存吗」的询问。
  理由是灵感最容易掉：宁可多存一条，也不能少存一段。
- **回看是事后行为，不是提交前的确认。** 录完给一段「已保存条」：播放（音频）、再录一条、收起。
- **文字单独设计。** 见 §7；这一版只做「就地一行、回车即存、存完收起」。

## 2. 结构

首页主区顺序不变：搜索区 → 捕捉区 → 列表面板（区间 24）。捕捉区有三种形态：

| 形态 | 内容 |
|---|---|
| tiles | 三个块：录音 / 视频 / 文字（按插件在场决定有几个） |
| workspace | 一行头部（媒体名 + 「收起」）+ 捕捉节点（`audio_capture` / `video_capture` / `input`） |
| saved | 已保存条：`已保存 · M:SS` + 播放（仅音频）+ 「再录一条」+ 「收起」 |

三种形态占的都是**捕捉区那一行的位置**，列表面板跟着上下移动 —— 不做弹层，也不新开一段主区。

## 3. 状态怎么走

| 动作 | 变成 |
|---|---|
| 点 Tile | tiles → workspace |
| 停止录制 | workspace → saved（提交成功之后） |
| 「再录一条」 | saved → workspace（重新挂上捕捉节点） |
| 「收起」 | workspace / saved → tiles |
| 录制中、上传中点「收起」 | 先收起；组件卸载时停止并提交，落库后不再把面板打开 |

- 录制、上传、设备门禁、时限、质量档都在客户端（引擎）里，插件不重复判断。
- 插件只持有当前工作区是哪个媒体、处于 workspace 还是 saved、以及刚存的那条的 media id。

## 4. 已保存条

- 只在刚存完的那一会儿存在，不是持久状态：收起 / 再录一条 / 换页就没了。
- 音频给播放（`Audio` 节点，点的时候才去向 media 取字节）。
- 视频**不给内联播放**：`Video` 节点是 16:9 全宽，塞不进一条窄条；视频在详情里看。
- **不给波形**：录完的静态波形要实时采样或预计算，v1 不做；录制中也不画电平。
- **不给撤销**：超时撤销是一套独立机制（倒计时 + 中途可取消），v1 不做。存错了去详情里归档。

## 5. 一次都不许丢

- 停止 = 落库。
- 组件卸载（收起、换页、关窗口前的最后一步）也要停止并落库，不能像以前那样静默丢弃。
- 视频上传失败：原地给失败原因 + 「重试」，字节还在内存里，不进 store。
- 已知限制：收起时视频还在上传，上传失败就没有界面可重试（只写日志）。要做成上传队列是后话。

## 6. 已知问题（v1 接受）

- **连录几条的标题一样**：`语音 0:12` / `语音 0:08` / `语音 0:31`，只能靠时长和时间区分。
  本地转写落地后会好；在那之前不加「起名」这一步。
- 工作区里没有波形，只有计时 —— 先这么用。

## 7. 文字这一页

文字不在这一版的设计范围内，只做一个最小形态：就地一行 `input`，回车落库，存完收起。

它真正要回答的问题不是版式，是**「什么时候算一条」**：回车、失焦、停手两秒，还是显式完成。
这个问题定了再单独设计（编辑器、草稿、转成需求 / 项目都从这里分叉）。

## 8. 边界

- 不加新节点：工作区与已保存条都用现有词表拼（`Panel` / `Row` / `Text` / `Button` / `Audio`）。
  SDK 与协议不变。
- 一屏仍然只有一个实心 accent（首页是搜索按钮）。工作区里的主操作是描边药丸「录音」/「停止」，
  不抢 accent。
- 三种媒体共用同一块版式，只换主体那个节点。下一版加媒体类型不该再改版式。

## 9. 怎么验证

- `uv run python scripts/check.py` 全绿。
- 人工：首页点「录音」→ 录 2 秒 → 停止 → 出现「已保存 · 0:02」→ 收起 → feed 顶部有那条 → 详情能播。
- 人工：录到一半直接点「收起」→ 条目仍然落库。
