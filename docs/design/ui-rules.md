# 界面底层规则

页面绝大多数由 Python 插件声明节点拼出来，TS 那边只负责画。节点一偏，后面能歪一大片，
所以规则要落在**词表与默认值**上，而不是靠每个插件自觉。

## 1. 面：只有三层

| 层   | token     | 用途                         |
| ---- | --------- | ---------------------------- |
| 主面 | `--paper` | 主区底色                     |
| 面板 | `--inset` | 内嵌面板、块、搜索胶囊、行条 |
| 壳   | `--desk`  | 图标栏、窗口底               |

不许第四层。**不许靠描边分层**：块与块的区分靠底色差，不靠 1px 线。

## 2. 强调

- 一屏**最多一个**实心 accent，代表主操作（首页就是搜索按钮）。
- 禁止描边式强调：不给卡片 / 按钮描边；不做 hover 变描边色；不给图标垫色底。
- 分隔的优先顺序：**留白 → 块面 → 1px 线**。线只用于"真的不同"的边界
  （例如面板里工具条与列表之间），不用于给每个块描个框。

## 3. 间距：只用这几个数

`4 / 8 / 12 / 16 / 24 / 32 / 48`。出现 13、18、22 这类值就是错的。

- 主区里**区与区**之间：24
- 面板内边距：12
- 块内边距：16
- 列表行与行：8
- 行内元素之间：8 / 12

## 4. 圆角

`6` 行内小件 · `10` 块与卡片 · `12` 面板 · `999` 药丸 / 搜索 / 主按钮。

## 5. 字级：一屏最多四级

`21/600` 标题 · `15` 正文 · `13` 次要 · `11` 元信息。
不许靠颜色加粗堆出第五级。

## 6. 文案

- 按钮 ≤ 6 字，只写"做什么"，不写"怎么做"。
- 不写说明书："说一句，存成语音"这种是在解释操作，不是给用户看的。
- 不写开发者词：接口、渲染、节点、属性、服务。
- 空状态：一行标题 + 最多一句提示，不写第二步该怎么办，技术原因不往界面里塞。

## 7. 主区的区（首页）

从上到下三个区，区间 24px：

1. **搜索区**：胶囊（`--inset` 底、全圆角、无描边），右侧一个实心 accent 提交。
2. **捕捉区**：三个块（`--inset` 底、圆角 10、无描边），只有图标 + 标题，没有说明文字。
   就地展开成工作区后，这一块变成一块 `--inset` 面板（圆角 12、内边距 12）：
   一行头部（媒体名在左、「收起」在右，两端对齐）+ 捕捉节点；存完之后收成「已保存」条，用同一档面板样式。
   录音的版式自上而下固定：**大圆钮**（这一屏唯一的实心 accent；录音中换 danger、暂停换 muted）→ 计时 →
   一行提示 → 暂停/继续与设备 → 整条波形。控制件别散到波形两侧。
3. **列表面板**：`--inset` 面板（圆角 12、内边距 12），顶上一行工具条（chip，无描边），
   下面是 `--paper` 实心行条（圆角 6、行间 8）。

## 8. 词表要跟着规则走

新增节点时必须能回答：它属于哪一层面、用哪档间距和圆角、有没有主操作。
答不上来就别加；也不许某个插件自己拼特例绕过去。
