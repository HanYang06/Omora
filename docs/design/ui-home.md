# 三栏首页（灵感）

这份文档把 2026-11-09 手绘稿的**区域、模式、词表**固定下来。上一轮只靠一张图口头描述，
没进仓库，实现就回到了"一页账本"。以后改首页先改这里。

## 1. 骨架

三栏，从左到右：

| 栏 | 宽度 | 归谁 | 内容 |
|---|---|---|---|
| 图标栏 | 56px | 母页面（引擎） | 每一页一个图标按钮；底部是连接状态 |
| 索引栏 | 280px | 页面（Split 的 side） | 当前集合的全部条目，自己滚动 |
| 主区 | 剩余 | 页面（Split 的 main） | 首页 / 结果 / 详情 / 捕捉，见下 |

页面只填自己那一页：图标栏是壳的，索引栏和主区是页面用 `Split(side, main)` 排出来的。
页面内容铺满主区，不再有 720px 居中。

母页面**不画页头**（没有标题 + 条数那一行）：数量这类信息由页面自己决定放哪
（首页放索引栏标题，结果页放主区文字）。`Snapshot.meta` 仍然在协议里，只是壳不画。

## 2. 主区的模式

同一页切换模式，索引栏不动：

| 模式 | 内容 |
|---|---|
| home | 搜索行 → 三个捕捉大按钮 → 工具条 → 推荐 feed |
| results | 搜索行 → 返回 → 结果列表（浏览器式：回车进结果页） |
| detail | 返回 + 时间 → 标题 → 媒体 → 置顶 / 归档 |
| capture_text | 返回 + 一行捕捉输入（回车保存，存完回 home） |
| capture_audio | 返回 + 音频捕捉条 |
| capture_video | 返回 + 视频捕捉条 |

## 3. 首页（就是"展览页"）

**只读。** 编辑不在这里。

1. **搜索行**：`Search`（自带下拉联想 + 右侧「搜索」按钮）。打字出联想，回车进 results。
   模糊 / 语义搜索留给 AI 插件，v1 是子串。
2. **三个捕捉大按钮**：`Tile` × 3 —— 录音 / 视频 / 文字。点一下进对应 capture 模式。
3. **工具条**：`Chip` × 4 —— 全部 / 置顶 / 最近 / 久未打开。v1 是 feed 的筛选，不做分页。
4. **推荐 feed**：`Card` 竖排。顺序 = 置顶优先，然后按创建时间倒序；「久未打开」筛
   创建超过 30 天的。没有条目时放 `Empty`：没灵感时给一句引导。

推荐算法的"定期把旧灵感滚回来"是 v2；v1 只做这四种排序。

## 4. 索引栏

`Rail("全部灵感", Item…)`：标题 + 全量条目（置顶在前）。点一行进 detail
（`Item(..., on_click=…)` 整行可点）。不在这里做归档 / 置顶，动作都在 detail 里。

## 5. 词表新增（SDK ↔ 引擎的合同）

| type | props | children | 画成 |
|---|---|---|---|
| `split` | — | [side, main] | `grid-template-columns: 280px 1fr`，撑满高度 |
| `rail` | title | 条目 | 索引栏：标题 + 可滚动列表 |
| `icon` | name | — | 20px 内联 SVG；名字不认识就画空位 |
| `tile` | icon, title, hint, on_click | — | 捕捉大按钮（图标在左，标题 + 说明） |
| `chip` | text, active, on_click | — | 工具条小药丸；active 只是样子 |
| `card` | title, text, meta, on_click | 可选媒体 | 推荐卡片，点整张进 detail |

图标名：`ideas` / `projects` / `requirements` / `settings` / `search` / `mic` / `video` /
`text` / `pin` / `archive` / `back` / `plus`。引擎不内置图标库，只用这几个内联路径。

## 6. 定下来的决定

- 搜索结果落在主区（索引栏不动），跟现在的 results 模式一致。
- 捕捉是**主区整页**，不是弹层；保存后回 home。
- 视频 v1 真做（HTTP 媒体通道已通）。
- 工具条 v1 = 全部 / 置顶 / 最近 / 久未打开。
- 图标栏 = 灵感 / 项目 / 需求 / 设置；项目、需求仍是空页占位。
- 图标内联 SVG，不引第三方图标库（依赖越少越好，词表也小）。

## 7. 这一版不做

语义 / 模糊搜索（等 AI 插件）、转写、深色主题、项目与需求页的真实内容、
feed 的推荐算法、窄屏适配。

## 8. 怎么验证

`uv run python scripts/check.py`：pytest（ideas 页行为 + 词表序列化）、ruff、mypy、
ui-engine 测试（shell / 卡片 / 捕捉按钮）与构建。
